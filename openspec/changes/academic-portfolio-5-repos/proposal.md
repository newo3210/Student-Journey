## Why

Traditional Full Stack Modern courses and junior/mid hiring screens expect a small set of classic demos: React UI, REST API, CRUD + DB, auth/roles, and one modern Next.js full-stack app — without AI or blockchain. This change freezes those five GitHub targets as an Academic Portfolio track.

## What Changes

- Add `docs/ACADEMIC_PORTFOLIO.md` profiling five repos (scope, stack, features, rubrics, defense bullets)
- Link Academic track from `docs/LEARNING_ROADMAP.md`
- Update `ARCHITECTURE_SDD.md` and `STUDENT_DECISION_LOG.md` for the academic (non-AI) portfolio intent
- Align `docs/base-standards.md` §0 to acknowledge Academic vs Advanced tracks

# JS Calculator (fundamentos)

Mini proyecto del **curso Full Stack — día 1**: variables, tipos, objetos, arrays/funciones básicas, operadores y ternario.

## Qué practica

| Concepto | Dónde se ve |
|---|---|
| `const` / `let` | referencias DOM y nombres de operación |
| `number`, `string`, `boolean` | parseo, mensajes, validación |
| Objetos | `operations` (nombre → función) |
| Funciones + parámetros | `add`, `subtract`, `multiply`, `divide`, `calculate` |
| Operadores | `+ - * /`, `===`, `&&` |
| Ternario | formato del resultado (`Number.isInteger ? ... : ...`) |
| Comentarios por bloque | secciones en `app.js` |

## Extra para practicar vos

1. Agregá `%` (resto / módulo).
2. Agregá un botón “limpiar” que vacíe inputs y resultado.
3. Guardá el último resultado en un array `history` y mostralo abajo.
